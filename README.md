🍔 Noisy Burger - Urban Street Food Website
The concept of this project was to create a visual experience that triggers an immediate appetite.

What I learned 🧠
-Color Theory: How to blend warm tones to create an inviting atmosphere.

-Dynamic Animations: Implementing auto-type animations to enhance user engagement.

-Advanced Layouts: Deepened my expertise in Flexbox and CSS Grid for building responsive and complex UI structures.

-Responsive Web Design (RWD): Using Media Queries and CSS Variables to ensure a seamless experience across all devices.
